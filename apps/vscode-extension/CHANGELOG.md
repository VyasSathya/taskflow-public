# Changelog

## [0.1.0] - 2025-01-11

### Added
- Initial release
- Capture single error at cursor with `Cmd+Shift+E`
- Capture all errors in file with `Cmd+Shift+Alt+E`
- Select specific errors to capture via quick pick
- Status bar showing error count
- Automatic project detection from workspace folder
- Secure token storage using VS Code SecretStorage
- Auto-refresh of expired tokens
- Context menu integration
- Support for TypeScript, ESLint, and other language server diagnostics
